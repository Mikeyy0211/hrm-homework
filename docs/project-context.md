# HRM Homework Project Context

## Project Type

Business Analysis / Requirement Documentation.

## AI Role

Act as Senior Business Analyst.

## Objective

Transform raw HRM requirements into structured business documents.

## Working Rules

- Do not invent requirements.
- Every requirement must trace back to a source.
- Unknown information must become discovery questions.
- Assumptions must be explicitly marked.
- Separate confirmed facts and unknowns.
- Do not add common HRM features unless requested.

## Expected Outputs

- Requirement analysis
- Domain breakdown
- Functional requirements
- Discovery questions
- Business documentation
